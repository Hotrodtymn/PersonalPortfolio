# e-portfolio-personal

## Personal portfolio website (static)

A personal portfolio built with HTML, CSS, and JavaScript. The entry page links stylesheets, browser-side scripts, and an EmailJS contact integration.

> **Project type:** Portfolio project. This README describes the checked-in source rather than promising production functionality.

## Getting started

Open `index.html` in a browser. Contact-form functionality requires the configured EmailJS service.

## Notes

This is a static portfolio implementation; see [thomas-babb-portfolio](https://github.com/Hotrodtymn/thomas-babb-portfolio) for the React portfolio.
